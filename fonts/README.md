# Fonts

Hier die vier Hausschriften ablegen (liegen im Drive unter Branding-Logos):

- GTAlpina-CondBold.otf
- GTAlpina-CondBoldItalic.otf
- Mabry Pro.otf
- Mabry Pro Bold.otf

Die Dateinamen müssen genau so heißen, sie sind in `index.html` im `@font-face`-Block referenziert.
Fehlen die Dateien, nutzt die Seite automatisch Fraunces und Figtree von Google Fonts.

Hinweis: Lizenz prüfen, ob die Schriften als Webfonts auf einer öffentlichen Seite ausgeliefert werden dürfen.
